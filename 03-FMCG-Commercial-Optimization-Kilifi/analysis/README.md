# Commercial Analytics & Modeling Pipeline

> **Executive Overview:** This directory contains the Python analytics pipeline powering the Meru Fresh Dairy Ltd. – Kilifi Expansion case study. The scripts execute exploratory data analysis, fit order-level driver models, and perform visit-level response surface modeling (RSM) on the experimental design matrix.

---

## 1. Pipeline Execution Flow

Execute scripts in sequential order from the repository root:

```bash
# 1. Generate underlying baseline datasets (N=6,591 visits)
python data/generate_dataset.py

# 2. Run EDA & driver screening
python analysis/01_eda_and_screening.py

# 3. Fit order-level commercial driver models (OLS & Logistic GLM)
python analysis/02_commercial_driver_models.py

# 4. Run DOE response surface regression & simulated profiler optimization
python analysis/03_doe_rsm_optimization.py
```

---

## 2. Analytics Script Specifications

| Script Name | Target Dataset | Primary Methodology | Statistical / Business Output |
| :--- | :--- | :--- | :--- |
| **`01_eda_and_screening.py`** | `kilifi_sales_visits_baseline.csv` | Cross-tabulation, funnel analytics, ANOVA screening | Reconciles KES 11,648,320 net revenue, 3,846 orders, 6,591 visits (58.41% conversion). Evaluates variance across 5 reps and 2 vehicles. |
| **`02_commercial_driver_models.py`** | Order-level subset ($N=3,846$) | Ordinary Least Squares (OLS) & Logistic Regression | Evaluates `order_total_kes ~ size_tier * shop_type` ($R^2 \approx 0.487, p < 0.0001$) and conversion probabilityGLM. |
| **`03_doe_rsm_optimization.py`** | 32-Run DOE Matrix | Response Surface Modeling (RSM) & Multi-Response Desirability | Evaluates `revenue_per_visit ~ credit_terms + visit_duration_min + context` ($R^2 \approx 0.7513$). Generates simulated optimal operating conditions. |

---

*Note: All experimental DOE outcomes and profit optimizations generated by `03_doe_rsm_optimization.py` represent **simulated/model-based predictions** intended for live 6-month market validation.*
